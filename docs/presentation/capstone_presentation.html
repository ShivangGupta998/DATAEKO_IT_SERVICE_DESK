Industry Challenges & Business Opportunity

SLA Breaches & Lost Tickets

Closed-Loop Resolution Cycle

  • 1 Multi-Channel Intake: Employees create tickets via Web Portal or directly via Slack Bot webhook.
  • 2 Auto-Assignment: Unassigned tickets are assigned strictly to registered Technicians (Role ID: 3) to prevent queue starvation.
  • 3 Pre-Breach Alerts: Slack channel alerts fire 30 minutes before SLA deadline expires.
  • 4 CSAT Rating Trigger: When resolved, requester receives an instant 1–5 star rating prompt with qualitative feedback.
Speaker Talking Points: The SLA engine isn't a static timestamp—it's a background worker constantly evaluating every open ticket against business hours and priority thresholds. It auto-notifies technicians on Slack before a breach occurs, keeping our compliance high.

Security & Authorization

Role-Based Access Control (RBAC) & Security

Role ID 1

Administrator

Full system oversight, user role editing, system configuration, executive reports access, and cloud backup management.

Role ID 2

Manager

Reviews & approves departmental access requests, monitors team ticket volume, and views department performance analytics.

Role ID 3

Technician / Agent

Assigned tickets in queue, manages asset inventories, posts internal investigation notes, and updates ticket status.

Role ID 4

Employee

Creates tickets, tracks personal asset assignments, browses Knowledge Base, submits access requests, and rates CSAT.

Cryptographic Safeguards: Bcrypt password hashing (salt rounds: 12) + Stateless JWT authorization bearer tokens with auto-expiration. Zero Hardcoded Credentials
Speaker Talking Points: Security isn't an afterthought. We implemented clean 4-tier Role-Based Access Control. Each API endpoint validates the role token before executing, ensuring employees can never view unassigned asset pools or approve their own access requests.
